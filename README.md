# Currículo web

Página de apresentação profissional de Filipe Bandeira, criada como exercício de desenvolvimento web a partir de um modelo com **HTML e W3.CSS**.

## Conteúdo

- Apresentação, formação e tecnologias de trabalho.
- Referências a projetos públicos.
- Links para GitHub e LinkedIn.

## Como executar

Requisitos: navegador moderno e conexão para carregar W3.CSS, Google Fonts e Font Awesome. Opcionalmente, use Python 3:

```sh
git clone https://github.com/FilipeBandeira/projeto-curriculo.git
cd projeto-curriculo
python3 -m http.server 8000
```

Abra `http://localhost:8000`. A página está em `index.html`, sem backend ou etapa de build. O crédito do modelo W3.CSS permanece na página.

## Evolução

Atualizar a apresentação à medida que novos projetos forem publicados e substituir dependências externas por recursos locais quando necessário.
